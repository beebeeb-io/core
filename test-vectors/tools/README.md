# test-vectors/tools

Generators for the direct-transfer vectors (task 2173). The JSON files are the contract; these scripts are how they are written, so a rule
change edits a script, regenerates the file, and the diff of the JSON is what a reviewer reads.

```sh
python3 test-vectors/tools/make_direct_transfer_vectors.py test-vectors/direct_transfer.json
python3 test-vectors/tools/make_direct_upload_vectors.py test-vectors/direct_upload.json
python3 test-vectors/tools/jitter_port.py     # a few jittered values, to eyeball the port
```

`jitter_port.py` is an independent Python port of the jitter rule of `UploadChunkState` (splitmix64 seed, xorshift64*, equal jitter), so the
jittered waits in `direct_upload.json` come from an implementation that does not share its code with the Rust they test. Expected values of the
other rows are hand-authored from the spec and from the server's own bodies; every upload row carries a `source`.

`make_owner_file_key_vector.py` independently generates the L8 `owner_wrapped_file_key` known answer using Python
`cryptography` (HKDF-SHA256 and AES-256-GCM). It replaces only that vector block, preserving every other byte:

```sh
python3 test-vectors/tools/make_owner_file_key_vector.py test-vectors/vectors.json
```

It uses the public fixed fixture inputs and canonical textual UUID bytes, matching L6's ID encoding. The Rust vector
regeneration test checks the production sealer against these independently generated bytes.

The four backup rule groups (LD-0113, `beebeeb_core::backup`) are written the same way: expected answers come from the
spec (`2026-11-06-backup-from-source-design.md` §4.2) and the device ids from `hashlib`, never from the Rust they test.
Each file is run by `cross_client_vectors` (`beebeeb-core/tests/consolidation/backup_*.rs`) and by every client's own
binding. `check-backup-vectors-generated.sh` (CI, with `--self-test`) fails when a committed `backup_*.json` is not
byte-for-byte what its generator writes: add a case in the generator, never in the JSON.

```sh
python3 -I test-vectors/tools/make_backup_protect_vectors.py test-vectors/consolidation/backup_protect.json
python3 -I test-vectors/tools/make_backup_device_vectors.py test-vectors/consolidation/backup_device.json
python3 -I test-vectors/tools/make_backup_root_vectors.py test-vectors/consolidation/backup_root.json
python3 -I test-vectors/tools/make_backup_plan_vectors.py test-vectors/consolidation/backup_plan.json
```

`check_version_metadata.py` independently derives the file/name subkeys, opens
the protected metadata vector with Python `cryptography`, and checks the exact
`version_id` / `version_counter` plaintext shape:

```sh
python3 test-vectors/tools/check_version_metadata.py test-vectors/vectors.json
```

`check_key_proof.py` independently derives both X25519 public keys, the shared
secret, HKDF MAC key and complete HMAC transcript for the key-proof vector:

```sh
python3 test-vectors/tools/check_key_proof.py test-vectors/vectors.json
```

`make_safety_number_vectors.py` independently writes `test-vectors/safety_number.json`, the contact safety numbers
(relayed-key pinning design D1 and D2: the email trimmed and lower-cased, then 5200 SHA-512 rounds with the key
appended, as Signal does), with `hashlib` only. `contact_keys`' own test runs every row against core, and
`scripts/check-test-vectors.sh` regenerates the file and fails on any byte that differs:

```sh
python3 -I test-vectors/tools/make_safety_number_vectors.py test-vectors/safety_number.json
```

`gen_name_clash_v1.py` writes `test-vectors/name_clash_v1.json`: numbered names (`report (2).pdf`), drive conflict
names (`report (conflict, <device>).pdf`) and the normalised form that decides when two names clash. It uses only
`unicodedata` and the simple case folding (statuses C and S) of `ucd/CaseFolding-17.0.0.txt`, never Python's full
`str.casefold`. `gen_case_fold_table.py` writes core's folding table, `beebeeb-core/src/name_tag/case_fold.rs`, from the
same Unicode file, at the version `unicode-normalization` pins. `scripts/check-test-vectors.sh` regenerates both and
fails on a difference.

```sh
python3 -I test-vectors/tools/gen_name_clash_v1.py test-vectors/name_clash_v1.json
python3 -I test-vectors/tools/gen_case_fold_table.py beebeeb-core/src/name_tag/case_fold.rs
```
